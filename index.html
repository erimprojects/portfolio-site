Whoami

Student software engineering, bouwer van webapplicaties

Ik ben Erim, student software engineering aan De Haagse Hogeschool. Ik werk het liefst aan projecten waar je het resultaat direct kunt gebruiken: een website voor een echte ondernemer, of een applicatie die een team dagelijks helpt bij zijn werk.

In teamprojecten werk ik veel met Java, daarnaast bouw ik zelf webapplicaties met HTML, CSS en JavaScript. Ik vind het belangrijk dat wat ik maak niet alleen werkt, maar ook leesbaar, toegankelijk en uitbreidbaar is.
