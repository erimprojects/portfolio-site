Projecten

Een selectie van projecten waar ik aan gewerkt heb. Per project staat kort wat het is, voor wie het bedoeld is en welke technieken ik gebruikt heb.

Uitgelicht werk

  • D'or Beauty - salonwebsite

    Een op maat gebouwde website voor een Nederlandse beautysalon. Klanten zien in een oogopslag welke behandelingen er zijn en maken direct een afspraak.

    Deze lichte, warme versie heeft een rustige typografie, scroll-animaties en een ingebouwde boekingsflow: kies een categorie, filter op behandeling en ga door naar datum en tijd. De demo is volledig zelf gebouwd, zonder framework.

    • HTML5
    • CSS3
    • JavaScript
    • Responsive design

    Bekijk de demo van de D'or Beauty salonwebsite

  • Casemanagementplatform voor een SOC

    Teamproject binnen mijn opleiding: een platform waarmee analisten in een Security Operations Center van een MSSP hun cases kunnen registreren, opvolgen en afsluiten.

    Mijn focus ligt op de structuur van de applicatie en de samenwerking in het team: werk opdelen, afspraken maken over de code en elkaars werk reviewen.

    • Java
    • Teamproject
    • Git

  • MuayCamp - iOS-app

    Een iOS-app voor Muay Thai: trainingskampen en lessen bekijken, je eigen sessies bijhouden en je voortgang volgen.

    Zelf gebouwd in Swift met SwiftUI. Ik heb de schermen, de navigatie en het lokaal opslaan van je trainingsdata opgezet.

    • Swift
    • SwiftUI
    • Xcode
    • iOS

  • Deze portfoliosite

    De site die je nu bekijkt. Een statische, responsieve portfoliosite die ik vanaf nul heb opgezet met semantische HTML5 en CSS3, zonder framework.

    De opzet is bewust uitbreidbaar: nieuwe projecten en blogposts voeg ik toe als losse article-blokken, en later als aparte pagina's in de mappen projecten/ en blog/.

    • HTML5
    • CSS3
    • Git
